# 🚀 Featured Projects

## 🏦 Secure Bank Management & Payment Processing System
Backend payment system with **ACID transactions** for safe fund transfers. Uses **idempotency** (database constraints) so a retried request never charges twice, and **JOIN FETCH** to fix Hibernate N+1 query problems.

**Tech:** `Java` `Spring Boot` `PostgreSQL`

---

## 🧭 [TalentPilot: Agentic AI Recruitment Automation](https://github.com/Abhishekkumar071/TalentPilot)
**Problem:** HR teams lose days on writing job descriptions, sorting resumes, running tests and drafting offers. TalentPilot takes a request like *"Hire a backend engineer"* all the way to an offer letter, and HR approves every key decision.

- Checkpointed **LangGraph** workflows that survive restarts and resume after days
- Hybrid resume screening: LLM rubric 45% + skills 25% + semantic similarity 15% + experience 15%, with resumes anonymized first
- Policy-grounded **RAG** (BM25 + embeddings merged with Reciprocal Rank Fusion)
- React portal with **MediaPipe** proctoring and an AI voice interview. Flags go to HR as evidence and never auto-reject

**Tech:** `Python` `FastAPI` `LangGraph` `React` `MediaPipe` `PostgreSQL`

---

## 🛡️ InsurAI: AI-powered Insurance Management Platform
Built during the **Infosys Springboard Virtual Internship 6.0** (Oct - Dec 2025). Replaces paper-based insurance workflows with one online portal.

- **50+ REST APIs** secured with **JWT and RBAC**
- AI chatbot for policy questions and a recommendation system for personalized suggestions
- Tested with **JUnit 5, Mockito and Postman**. Deployed on **AWS EC2** (backend) and **S3** (frontend)

**Tech:** `Java` `Spring Boot` `MySQL` `React` `AWS`
